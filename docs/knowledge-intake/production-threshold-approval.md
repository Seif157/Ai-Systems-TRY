# Production threshold approval procedure

Production approval requires an authoritative document owner, recorded approval identity and
timestamp, effective dates, customer/legal-entity scope, module/permission scope, classification
review, human relevance judgements, independent holdout review, zero authorization leaks, and an
explicit signed threshold decision. The decision must bind corpus, labels, generation, embedding
profile, runtime identity, resource policy, retrieval policy, and candidate identity.

Typed contracts validate structure only. They cannot prove a human signature, reviewer identity,
or approval-service authenticity. Those guarantees require an independently controlled service.
