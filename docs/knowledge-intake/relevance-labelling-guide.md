# Relevance-labelling guide

Use trained human reviewers who cannot see candidate scores. Grade each stable document/section
reference from 0 (irrelevant) through 3 (direct answer), record disagreements, and adjudicate them
independently. Include expected-empty, adversarial, cross-customer, module, entity, classification,
and effective-date cases. Machine-authored synthetic references are not human labels or production
evidence. Never place query text or labels in runtime audit events.
